# Platform Dashboard

React + TypeScript + Tailwind CSS admin dashboard.

## Setup

```
npm install
npm run dev
```

## Build

```
npm run build
```

Additional quality gates:

```
npm run typecheck
npm run lint
npm test
```

## Deploy

Deploy to Vercel by connecting this repository. The included `vercel.json` keeps client-side routes such as `/profile` working on direct navigation.
